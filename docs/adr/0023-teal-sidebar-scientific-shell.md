# 工作台改为青绿主色与左侧 Sidebar 壳层

工作台视觉由 ADR 0022 的深蓝顶栏 SaaS 改为青绿主色（`#167D70` / `#105E55`）与左侧固定 Sidebar + 精简顶栏，以贴近科研 workflow 平台。系统字体栈声明 Inter / Noto Sans SC / IBM Plex Mono 并回退到系统字体。同页四步提交流不改上传与入队 API；提交成功跳转任务详情。仓库根目录 GitHub Pages 静态演示本轮同步为同一壳层与配色，并保留「静态预览、无后端」横幅，不用假数据伪装可提交或可轮询。
